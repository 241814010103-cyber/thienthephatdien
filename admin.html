Kết nối với GitHub

Dùng fine-grained personal access token chỉ có quyền Contents: Read and write đối với repository thienthephatdien. Token chỉ giữ trong bộ nhớ tab đang mở, không lưu vào website hoặc trình duyệt.

Tạo token tại GitHub → Fine-grained tokens. Chọn đúng repository, thời hạn ngắn và giới hạn Contents. Không chia sẻ token với bất kỳ ai và không nhập token vào trang khác.
